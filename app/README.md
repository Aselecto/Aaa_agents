# Aaa_agents
Проект по разработке мультиагентной системы генерации комплексных представлений из хаотичных данных
Мультиагентный ИИ-Конвейер (MVP)

## 🛠 Инструменты разработки (Для команды)

Перед отправкой кода в Git обязательно прогоняйте утилиты проверки:
```bash
ruff check . --fix   # Авто-исправление стиля и сортировка импортов
ruff format .        # Форматирование кода
mypy app/            # Проверка типов данных
```

## 📝 Стандарт логирования
Вместо `print()` используем `get_logger()` из `app.config`.
* `logger.debug()` — подробности для разработчика (скрыты в проде).
* `logger.info()` — ключевые шаги (Агент запущен, ТЗ создано).
* `logger.warning()` — некритичные сбои (Gemini выдала грязный JSON, но мы его очистили).
* `logger.error()` — критический сбой агента (упали вычисления, превышен лимит циклов правок).
